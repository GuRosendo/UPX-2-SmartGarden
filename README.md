# UPX-2 Smart Garden

Projeto acadêmico desenvolvido para a disciplina **UPX-2**, com o objetivo de criar um sistema de **gestão e controle de hortas comunitárias**.

A aplicação foi pensada para auxiliar na organização de hortas coletivas, permitindo o acompanhamento de cultivos, gestão de participantes e controle das atividades realizadas no espaço (Hortas, plantios e etc.).

---

## Tecnologias utilizadas

* Java
* MySQL
* JDBC
* Programação Orientada a Objetos

---

## Objetivo do projeto

O sistema foi idealizado para facilitar a administração de hortas comunitárias, permitindo:

* Cadastro de usuários participantes
* Controle de áreas de cultivo
* Registro de plantas cultivadas
* Organização de atividades na horta
* Gestão básica de informações do projeto

---

## Contexto acadêmico

Este projeto foi desenvolvido como parte da disciplina **UPX-2**, durante o curso de **Análise e Desenvolvimento de Sistemas**.

O objetivo principal foi aplicar na prática conceitos como:

* Programação orientada a objetos
* Integração com banco de dados
* Estruturação de sistemas em Java
* Modelagem de dados

---
